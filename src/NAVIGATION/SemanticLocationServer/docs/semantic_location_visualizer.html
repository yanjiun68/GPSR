    How the visualization maps to the Python code

    Pose adapter

    SemanticLocationServerNode._read_pose()

    Selects TF or AMCL and rejects stale AMCL samples.

    Geometry

    SemanticClassifier.classify()

    Uses polygon containment, then finds a waypoint only inside the confirmed room.

    Runtime stability

    SemanticStateTracker.update()

    Commits the first reliable state immediately and debounces later signatures.

    ROS interface

    _update() / _handle_get_current()

    Publishes a retained snapshot and returns that same snapshot from the service.
